# Blanko v0.1.0-beta.4 — تصحيح نسخة Windows

هذه حزمة تصحيح لنسخة Windows؛ بيانات اللوحات ومسار حفظها لم يتغيّرا.

نُشر الإصدار بعد نجاح وظائف البناء والتحقق السبع في [مسار الإصدار](https://github.com/Ahmedelsapagh10/Blanko/actions/runs/40042476050)، بما فيها إعادة فحص Windows Release والشعار وفحص الملفات العامة الأربعة وبصماتها وسلامة الأرشيفات.

- أيقونة Blanko الحقيقية بدل أيقونة Flutter الافتراضية، بدقات16–256بكسل.
- رقم البناء ظاهر في عنوان نافذة Windows: `Blanko 0.1.0 (build 4)`.
- استمرار دعم حفظ `.wboard` وتصدير PNG واستيراد الصور والمشاريع على Windows، الذي أُضيف في beta.3. نسخة beta.1 كانت تعطل سهم الملفات على Windows صراحةً.

اجتاز مرشح Windows [الفحص الفعلي في CI](https://github.com/Ahmedelsapagh10/Blanko/actions/runs/40042010681):19اختبارًا مركزًا، ثم تشغيل Release بتخزينه الافتراضي الحقيقي. قائمة الملفات ونافذة PNG وزر التصدير متاحون؛ رسم وصورة أصليّة حُفظا وأُعيد فتحهما من عملية Windows جديدة بالمحتوى والإحداثيات نفسها. أُعيد بناء مدخل التطبيق العادي وفُحص الشعار المضمّن داخل EXE، ثم نجح تشغيله وتحزيمه. لا يوجد تغيير لصيغة اللوحات أو مسارها.

للتثبيت: فك ZIP كاملًا في مجلد جديد وشغّل `whiteboard.exe` مع مجلد `data` وملفات DLL بجانبه. لا تحذف بيانات التطبيق ولا تزل اللوحات القديمة. للحفظ الخارجي اضغط سهم التنزيل ثم `Save As .wboard` أو `Export PNG`؛ الحفظ المحلي تلقائي عند ظهور `Saved locally`.

تظل حوارات اختيار الملفات يدويًا على جهاز Windows للمستخدم، والأجهزة الفعلية الأخرى والتوقيع التجاري ضمن حدود النسخة التجريبية. Android يستخدم مفتاح المالك الثابت؛ beta.1 القديم مختلف ويحتاج نسخة `.wboard` قبل أي إزالة. لا توجد IPA عامة، والويب ينتظر رابط المالك.
