# Blanko v0.1.0-beta.2 — إصلاحات المنصات والحفظ

نسخة تجريبية مصححة، بنفس أدوات Blanko الحالية ودون تغيير صيغة اللوحات.

- إصلاح إعادة فتح اللوحات ومكتبتها على Windows؛ اختلاف فواصل المسار كان يمنع العثور على ملفات صحيحة. البيانات القديمة لا تحتاج حذفًا أو ترحيلًا.
- تفعيل حوارات Windows وLinux الأصلية لاستيراد الصور والمشاريع وحفظ PNG و`.wboard`، مع حدود للقراءة وإلغاء آمن وكتابة ذرية.
- حماية استيراد macOS من تحميل ملفات كبيرة بالكامل في الذاكرة: الصور16MiB والمشاريع64MiB، وفق حدود المحتوى الحالية.
- توقيع Android بمفتاح إصدار المالك، مع فحص بصمة الشهادة في CI. المفتاح وكلمات المرور خارج Git والسجلات.

**Android beta.1:** التوقيع القديم Debug ومختلف. لا نضمن تثبيت هذا الإصدار فوقه. صدّر مشاريعك إلى `.wboard` أولًا قبل أي إزالة للتطبيق؛ إزالة التطبيق قد تمحو اللوحات والصور المحلية.

## التحقق

اختبارات المحرر داخل المحرك على Windows وLinux وmacOS وAndroid وiOS تغطي الرسم والتراجع والحفظ وإعادة فتح مخزن معزول والصور الأصلية وملف مشروع وPNG حقيقي. إعادة فتح المخزن في هذه الاختبارات ليست اختبار إغلاق عملية النظام. تشغيل نسخ Release متحقق على منصات سطح المكتب الثلاث وAndroid؛ iOS Release مبني دون توقيع ومحاكي iPhone اختُبر بصريًا مع إعادة تشغيل عملية التطبيق وتصدير PNG.

اختيار الملفات يدويًا على Windows/Linux وAndroid، الأجهزة الفعلية والتابلت والقلم وتوزيعات Linux الأخرى ليست مؤهلة بالكامل. macOS Ad-hoc وغير موثق من Apple؛ Windows غير موقّع Authenticode. لا توجد IPA أو استضافة Web ضمن هذا الإصدار. هذه نسخة Beta، ولا يوجد ضمان خلو جميع الأجهزة من الأخطاء.
