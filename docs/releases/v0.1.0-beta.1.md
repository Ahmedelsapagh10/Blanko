# Blanko v0.1.0-beta.1 — نسخة تجريبية عامة

سبورة رقمية مفتوحة المصدر تحت MIT، مبنية بـ Flutter وتحتفظ باللوحات محليًا دون حساب. هذا إصدار Beta وليس Stable.

الرسم والهايلايتر والممحاة والأشكال والأسهم، النص العربي والإنجليزي والملاحظات، الصور والإطارات والتجميع، التراجع والحفظ المحلي، والثيمات الفاتحة والداكنة متاحة. PNG يحافظ على النسب باستخدام Fit، وملفات `.wboard` تتضمن الصور الأصلية على المنصات التي تدعم اختيار الملفات.

## التحميل

- [Windows x64 — ZIP كامل](https://github.com/Ahmedelsapagh10/Blanko/releases/download/v0.1.0-beta.1/Blanko-Windows-x64.zip)
- [Linux x64 — bundle كامل](https://github.com/Ahmedelsapagh10/Blanko/releases/download/v0.1.0-beta.1/Blanko-Linux-x64.tar.gz)
- [macOS Intel وApple Silicon](https://github.com/Ahmedelsapagh10/Blanko/releases/download/v0.1.0-beta.1/Blanko-macOS.zip)
- [Android — APK تجريبي](https://github.com/Ahmedelsapagh10/Blanko/releases/download/v0.1.0-beta.1/Blanko-Android.apk)
- [SHA256SUMS.txt](https://github.com/Ahmedelsapagh10/Blanko/releases/download/v0.1.0-beta.1/SHA256SUMS.txt)

فك حزم سطح المكتب بالكامل. Windows: شغّل `whiteboard.exe` مع ملفات DLL وdata؛ Linux: `./bundle/whiteboard` مع lib وdata؛ macOS: انقل `Blanko.app` إلى Applications. Android: API24+، ثبّت APK بعد التحقق من مصدره وبصمته.

> **تنبيه Windows (2026-10-23):** اكتشف اختبار Windows الفعلي خطأً في مقارنة مسارات ملفات اللوحات في beta.1 قد يمنع إعادة فتحها. الإصلاح موجود في المصدر ابتداءً من `a2b99a1` واجتاز اختبارات Windows. لا تعتمد على حزمة beta.1 لعمل مهم؛ لا تحذف بيانات التطبيق لمحاولة الإصلاح. الإصلاح منشور في beta.3 المرتبط أعلاه.

## التحقق والحدود

- [بناء المنصات الأربع والتحليل والاختبارات نجح في CI](https://github.com/Ahmedelsapagh10/Blanko/actions/runs/39794439149). حُمّلت الملفات الأربعة وفُحصت بنيتها وطابقت SHA-256؛ نجاح البناء لا يثبت التشغيل على كل جهاز.
- Windows وLinux: التشغيل الفعلي غير متحقق؛ استيراد الصور وفتح/حفظ `.wboard` وتصدير PNG غير متاحين حاليًا.
- macOS: Universal، توقيع Ad-hoc دون Developer ID أو Notarization. Android: توقيع Debug مؤقت، وليس مفتاح توزيع إنتاجي دائم؛ تشغيل الحزمة على جهاز غير متحقق.
- لا تُزل التطبيق الحالي لتجاوز اختلاف توقيع Android قبل تصدير نسخة احتياطية. إعادة التثبيت أو مسح بيانات الموقع قد يفقدك البيانات المحلية.
- الحفظ التلقائي ليس نسخة احتياطية. صدّر `.wboard` دوريًا خارج بيانات التطبيق. PNG لا يعيد مشروعًا قابلًا للتحرير.
- iPhone اختُبر على المحاكي؛ التابلت والأقلام وضغط القلم والأداء الكثيف غير مؤهلة بالكامل. لا توجد IPA أو استضافة Web ضمن هذا الإصدار.
