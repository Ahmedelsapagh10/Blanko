# Blanko v0.1.0-beta.3 — إصلاحات المنصات والحفظ

نسخة تجريبية مصححة، بنفس أدوات Blanko الحالية ودون تغيير صيغة اللوحات.

- إصلاح إعادة فتح اللوحات ومكتبتها على Windows؛ البيانات القديمة لا تحتاج حذفًا أو ترحيلًا.
- حوارات Windows وLinux الأصلية لاستيراد الصور والمشاريع وحفظ PNG و`.wboard`، مع قراءة محدودة وكتابة ذرية.
- حماية استيراد macOS من تحميل ملفات كبيرة بالكامل في الذاكرة.
- Android برقم بناء3، موقّع بمفتاح إصدار المالك الثابت. CI يتحقق من جميع شهادات التوقيع ويدعم صيغ أدوات SDK المختلفة؛ المفتاح وكلمات المرور خارج Git والسجلات.

**Android beta.1:** التوقيع القديم Debug ومختلف. صدّر مشاريعك إلى `.wboard` قبل أي إزالة للتطبيق؛ إزالة التطبيق قد تمحو اللوحات والصور المحلية. لا يوجد ضمان تحديث مباشر فوق beta.1.

اختبارات المحرر داخل المحرك والحفظ والصور وPNG نجحت على Windows وLinux وmacOS وAndroid وiOS. تشغيل Release تحقق على منصات سطح المكتب الثلاث وAndroid. المحاكيان Android وiPhone اختُبرا بصريًا للرسم وإعادة تشغيل التطبيق وحفظ PNG؛ Android اختُبر أيضًا لحفظ/استيراد المشاريع والصور وبقائها بعد إعادة التشغيل. iOS Release مبني دون توقيع ولا توجد IPA عامة.

اختيار الملفات يدويًا على Windows/Linux، مزودو ملفات Android الآخرون، الأجهزة الفعلية والتابلت والقلم وتوزيعات Linux الأخرى ليست مؤهلة بالكامل. macOS Ad-hoc وغير موثق من Apple، وWindows غير موقّع Authenticode. Web مؤجل حتى يوفر المالك رابطه. هذه نسخة Beta وليست اعتمادًا لكل الأجهزة.
